# Architrave requirements

Source of truth for Architrave's own development (spec-driven, see
`agents/architrave.agent.md`). Code and test output outrank this file.

## Current tasks

Only three task statuses are used:

- **Not started**: implementation has not begun.
- **Started**: implementation is underway but unfinished.
- **Code ready**: implementation is finished. Review is not required to reach this status.

Finish the code for every feature first. Then review the complete feature set
together, once. Do not review features individually or hold their progress
status back while waiting for review. Review results and release checks are
separate from task status.
